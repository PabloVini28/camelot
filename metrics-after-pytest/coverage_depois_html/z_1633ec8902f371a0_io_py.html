22def _detect_flavor(filepath, password=None, page=1, png_path=None): 

23 """Pick the most appropriate flavor for a single PDF page. 

24 

25 Renders ``page``, thresholds it, and counts ruled horizontal and 

26 vertical line segments. Used when the caller passes ``flavor="auto"`` 

27 (once per requested page, so a document with text-only cover pages and 

28 ruled tables deeper in is routed correctly per page). 

29 

30 Returns 

31 ------- 

32 str

34 ``"network"`` (else). ``"network"`` is also the fallback when 

35 rendering itself fails (e.g. unreadable PDF, missing backend 

36 dependencies) — the assumption is that giving the text-based parser 

37 a chance is more useful than raising before parsing starts.

111def _validate_per_page(per_page_norm, global_flavor): 

112 """Validate each per-page override against its effective flavor. 

113 

114 Each entry's flavor is either an explicit override (must be one of 

115 the four concrete flavors — ``"auto"`` doesn't make sense 

116 page-by-page) or the global flavor. All non-flavor kwargs are then 

117 checked with the existing :func:`validate_input` against that 

118 effective flavor. 

119 """ 

120 for page_no, overrides in per_page_norm.items(): 

121 page_flavor = overrides.get("flavor", global_flavor) 

122 if page_flavor not in ("lattice", "stream", "network", "hybrid", "ml"): 

123 raise NotImplementedError(

125 " one of: 'lattice', 'stream', 'network', 'hybrid', 'ml'." 

126 " ('auto' is only valid as the global flavor.)" 

127 ) 

128 page_kwargs = {k: v for k, v in overrides.items() if k != "flavor"} 

129 validate_input(page_kwargs, flavor=page_flavor)

145 r"""Read PDF and return extracted tables. 

146 

147 Note: kwargs annotated with ^ can only be used with flavor='stream' or flavor='network' 

148 and kwargs annotated with * can only be used with flavor='lattice'. 

149 The hybrid parser accepts kwargs with both annotations. 

150 

151 Parameters 

152 ---------- 

153 filepath : str, Path, bytes, or binary file-like 

154 Source PDF. Accepts a filesystem path / URL, a ``bytes``-like 

155 object, or any binary stream with a ``.read()`` method 

156 (``io.BytesIO``, an open ``"rb"`` file, ``requests`` response 

157 ``.raw``, etc). For in-memory inputs the bytes are spilled to 

158 a temporary file once and cleaned up on context-manager exit, 

159 so the Lattice OpenCV image-conversion backend keeps working 

160 unchanged. Originally requested in #170 / #245 / #270. 

161 pages : str, optional (default: '1') 

162 Comma-separated page numbers. 

163 Example: '1,3,4' or '1,4-end' or 'all'. 

164 password : str, optional (default: None) 

165 Password for decryption. 

166 flavor : str (default: 'lattice') 

167 The parsing method to use. Valid values: 

168 

169 - ``'lattice'`` (default): line-ruled tables. 

170 - ``'stream'``: borderless tables with whitespace-separated columns. 

171 - ``'network'``: borderless tables via text-edge alignment connectivity. 

172 - ``'hybrid'``: combines layout- and image-based analysis. 

173 - ``'ml'``: neural table-structure recognition (Table Transformer) 

174 for the structure, with cell text filled from the PDF's own text 

175 layer (no hallucinated values). Requires the optional ML 

176 dependencies: ``pip install 'camelot-py[ml]'``. Best for 

177 borderless tables where the heuristic parsers plateau. 

178 - ``'auto'``: detect the flavor **per page** (count ruled lines on 

179 each rendered page) and parse each group accordingly — ruled 

180 pages via ``lattice`` with ``engine='combined'``, the rest via 

181 ``network`` — then merge. Handles documents that mix text-only 

182 cover pages with ruled tables deeper in. A ``UserWarning`` reports 

183 the per-page choices. (More accurate but slower, since it renders 

184 every page for the probe.) 

185 suppress_stdout : bool, optional (default: False) 

186 Suppress logs and warnings. 

187 parallel : bool, optional (default: False) 

188 Process pages in parallel using all available cpu cores. 

189 cpu_count : int, optional (default: None) 

190 Maximum number of worker processes when ``parallel=True``. ``None`` 

191 (default) uses all available cores. Values are clamped to 

192 ``[1, multiprocessing.cpu_count()]``. Ignored when 

193 ``parallel=False``. 

194 layout_kwargs : dict, optional (default: {}) 

195 A dict of `pdfminer.layout.LAParams 

196 <https://pdfminersix.readthedocs.io/en/latest/reference/composable.html#laparams>`_ kwargs. 

197 per_page : dict, optional (default: None) 

198 Per-page parameter overrides. Maps a 1-indexed page number (int 

199 or str) to a dict of any keyword argument otherwise valid for 

200 ``read_pdf``. Values supplied here override the globally-supplied 

201 kwargs for that one page only — every other page keeps the global 

202 values. Useful for multi-layout PDFs where different pages need 

203 different ``table_areas``, ``columns``, ``flavor``, etc. The 

204 per-page ``flavor`` itself may be overridden; the global flavor 

205 applies otherwise. Originally proposed by @sverma25 in #41. 

206 

207 Example:: 

208 

209 tables = camelot.read_pdf( 

210 "report.pdf", 

211 pages="1-3", 

212 flavor="stream", 

213 split_text=True, 

214 per_page={2: {"table_areas": ["120, 210, 400, 90"]}}, 

215 ) 

216 

217 Here pages 1 and 3 use the global ``flavor="stream", split_text=True`` 

218 only; page 2 uses both *and* the page-specific ``table_areas``. 

219 table_areas : list, optional (default: None) 

220 List of table area strings of the form x1,y1,x2,y2 

221 where (x1, y1) -> left-top and (x2, y2) -> right-bottom

243 strip_text : str or sequence of str, optional (default: '')

245 assignment. A ``str`` strips per-character — every character in 

246 the string is removed wherever it appears (e.g. ``" \n"`` drops 

247 all spaces and newlines). A list/tuple of ``str`` strips whole 

248 substrings (e.g. ``["[1]", "[2]"]`` removes those footnote 

249 markers but leaves bare ``[``/``]`` alone). Whole-substring

278 Direction in which text in a spanning cell will flow.

280 Tolerance parameter used to merge close vertical and horizontal

283 Tolerance parameter used to decide whether the detected lines

290 <https://docs.opencv.org/2.4/modules/imgproc/doc/miscellaneous_transformations.html#adaptivethreshold>`_. 

291 threshold_constant* : int, optional (default: -2)

296 <https://docs.opencv.org/2.4/modules/imgproc/doc/miscellaneous_transformations.html#adaptivethreshold>`_. 

297 iterations* : int, optional (default: 0) 

298 Number of dilation passes applied to close small gaps in the 

299 line mask. 

300

302 <https://docs.opencv.org/2.4/modules/imgproc/doc/filtering.html#dilate>`_.

304 Number of erosion passes applied **after** dilation. Set equal

306 in ruled lines without thickening the mask overall (which 

307 avoids the spurious extra-row artefact reported in #363). (#363) 

308 backend* : str, optional by default "pdfium" 

309 The backend to use for converting the PDF to an image so it can be processed by OpenCV. 

310 use_fallback* : bool, optional 

311 Fallback to another backend if unavailable, by default True 

312 resolution* : int, optional (default: 300) 

313 Resolution used for PDF to PNG conversion. 

314 engine* : str, optional (default: 'combined') 

315 Line-detection engine for ``flavor='lattice'`` (and the lattice 

316 half of ``flavor='hybrid'``): 

317 

318 - ``'combined'`` (default): render the page and detect ruled lines 

319 with OpenCV **and** union in the ruled lines read from the PDF's 

320 native vector graphics, so tables whose rules render faintly 

321 (vector strokes, anti-aliasing) are still found. Safe by 

322 construction — raster always runs, vector lines can only add, and 

323 they're clipped to ``table_regions`` — so it never does worse 

324 than ``'raster'`` (#763). 

325 - ``'raster'``: render the page and detect ruled lines with OpenCV 

326 only — the pre-#763 behaviour. 

327 - ``'vector'``: detect tables straight from the PDF's vector ruled 

328 lines, skipping rasterisation entirely — the fastest path, for 

329 PDFs whose tables are drawn with real vector strokes (#763). 

330 

331 With ``flavor='hybrid'`` the same choices select how its lattice 

332 half finds ruled lines; ``engine='vector'`` there is the 

333 **render-free hybrid** — vector ruled lines merged with the network 

334 text-edge alignment — for partial-ruled / borderless tables at 

335 roughly an order of magnitude less time than the raster path (#39).

341 Notes 

342 ----- 

343 **Encrypted PDFs / extraction permissions** (#590). Camelot honours the 

344 ``/Encrypt`` dictionary's text-extraction permission: ``read_pdf`` raises 

345 :class:`playa.exceptions.PDFTextExtractionNotAllowed` if the PDF is 

346 encrypted and the user-password permission set forbids text extraction. 

347 The check fires on the document object returned by ``playa.open`` while 

348 the encryption metadata is still attached — this is a real behavioural 

349 change vs the pre-1.0 backend, where per-page temp-PDF splitting 

350 silently dropped the metadata so the check was effectively a no-op. 

351 Note: PDF spec only enforces the flag through the encryption layer — 

352 for **unencrypted** PDFs that carry a "no extraction" claim via 

353 ``/Perms``, there is no enforcement mechanism and Camelot extracts. 

354 Supplying the document owner password through ``password=`` bypasses 

355 the user-password permission set (matches every other PDF tool).
